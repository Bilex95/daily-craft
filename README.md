# 🛠️ Daily Craft

**One small, well-made project every day — at the intersection of UI/UX design and software testing.**

Every morning this repo grows by one self-contained mini-project: a polished UI component, a CSS layout study, a Playwright or Cypress test suite, an API testing kata, an accessibility audit exercise, or an interactive UX pattern demo. Each project is small enough to read in ten minutes and real enough to learn from — or contribute to.

Maintained by [@Bilex95](https://github.com/Bilex95) · designer & QA engineer · Next.js / Tailwind / Playwright / Cypress

## How it works

A scheduled GitHub Action runs daily:

1. **Picks a category** from a weekly rotation (UI, CSS, Playwright, Cypress, API testing, accessibility, UX patterns).
2. **Generates a fresh brief and starter code** using the Claude API — checked against every previous project so ideas never repeat.
3. **Commits the project** to `projects/YYYY-MM-DD-name/` and rebuilds the index below.
4. **Opens a `good first issue`** scoped to under an hour of work, so anyone can jump in.

The automation is fully open — see [`.github/workflows/daily-project.yml`](.github/workflows/daily-project.yml) and [`scripts/`](scripts/). If the API is ever unreachable, a local template kata keeps the streak alive.

## Contributing

Every project ships with open improvement ideas, and there's always at least one fresh [`good first issue`](../../issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22). See [CONTRIBUTING.md](CONTRIBUTING.md) — PRs of any size are welcome, from a typo fix to a full refactor.
